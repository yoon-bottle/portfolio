정의

관광객·지역 주민·어민이 여러 서비스의 정보를 따로 찾아보는 수고를 줄이기 위한 지역 정보 챗봇입니다. 디지털 트윈과 외부 API의 정보를 연결해 이동 계획, 날씨, 해양 상황에 관한 질문에 답하도록 개발했습니다.

관광지 추천만으로는 날씨나 해양 상황을 함께 고려하기 어렵습니다. 관광·기상·해양 에이전트가 각각의 관점에서 답변을 생성하고 검토하는 구조를 적용했습니다.

내용

담당 범위

4인 팀에서 개발을 주도하고, LangGraph 기반 에이전트 오케스트레이션을 담당했습니다. 질문별 역할 배정, 답변 생성·검증, 피드백 반영과 반복 종료, 최종 요약을 하나의 워크플로우로 연결했습니다. 지도 연동과 음성 입출력 등 사용자 기능도 구현했습니다.

답변 생성과 검증

  1. 역할 배정: 질문과 관련성이 높은 에이전트를 답변 생성자로, 나머지 두 에이전트를 검토자로 지정
  2. 초안 생성: 담당 에이전트가 도구를 호출해 필요한 정보를 조회하고 답변 작성
  3. 병렬 검토: 다른 두 에이전트가 각 분야의 정보 누락과 보완 사항 검토
  4. 피드백 반영: 검토 결과를 모아 답변 수정, 검토 통과 또는 반복 횟수 상한에 따른 종료
  5. 최종 응답: 답변 요약과 표현 정리, 관련 장소 추출 및 지도 표시

예를 들어 관광 에이전트가 이동 계획을 제안하면, 기상·해양 에이전트가 날씨와 해안 상황을 검토합니다. 분야별 API 조회 결과를 답변 수정에 반영하도록 구성했습니다.

서비스 화면

관광 장소·경로, 기상 예보·특보, 디지털 트윈 데이터를 챗봇에 연결했습니다. 답변에 등장한 장소는 지도에 표시하고, 음성 입력·읽어주기 기능을 추가했습니다.

결과

2025 디지털 트윈 구룡포 AI 해커톤에서 장려상(4위)을 수상했습니다. 관광·기상·해양 정보 조회부터 답변 검토, 지도 표시까지 연결한 챗봇을 구현하고 발표 데모로 시연했습니다.

  • 주최: 과학기술정보통신부, 한국지능정보사회진흥원, 경상북도, 포항시
  • 주관: POSTECH POIC 미래도시연구센터

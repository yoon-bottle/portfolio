정의

게임 QA 자동화 비용을 줄이기 위해, 모바일 게임 화면을 읽고 튜토리얼과 메뉴를 스스로 진행하는 GUI 에이전트를 개발·평가한 프로젝트입니다.

내용

모델 평가와 학습 데이터

오픈소스 GUI 모델을 비교하고, UI-TARS 모델의 플레이 기록을 활용해 LoRA·DPO 학습을 진행했습니다. 사람 시연 대신 에이전트가 직접 플레이하며 남긴 기록을 출발점으로 사용했습니다.

선호도 학습

플레이 단계마다 화면, 모델의 응답, 실행 결과와 게임 기록을 남겼습니다. 이후의 진행 여부를 바탕으로 자동 점수를 매기고, 비슷한 장면에서 상대적으로 잘 진행한 행동과 그렇지 않은 행동을 선호도 쌍으로 구성했습니다.

이 쌍을 사용해 DPO로 학습했고, 선택된 응답을 따라 하는 학습 손실도 추가했습니다. 반복 학습 과정에서는 이전 데이터를 함께 사용해 이미 배운 행동을 유지하려고 했습니다.

결과

가장 나았던 학습본은 한 차례 평가 플레이에서 튜토리얼 완료에 필요한 행동 수를 기본 모델 360스텝에서 113스텝으로 줄였습니다.

학습 과정에서 확인한 점

특정 성공 행동을 집중적으로 학습시키면 다른 행동을 덜 수행하는 문제가 나타났습니다. 학습 데이터에 필요한 행동이 충분히 포함돼 있는지와, 반복 학습 중 기존 능력이 유지되는지를 함께 확인해야 했습니다.
